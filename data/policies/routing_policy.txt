[ROUTING MATRIX POLICY]
- Categories: billing, technical, refund, account, shipping, feedback, security, other
- If ticket involves invoices, incorrect charges, subscription renewals -> Category: "billing", Queue: "billing_default_queue"
- If ticket involves bugs, app crashes, system outages, API errors -> Category: "technical", Queue: "tech_support_queue"
- If ticket explicitly requests money back, return, or refund dispute -> Category: "refund", Queue: "refund_expert_queue"
- If ticket mentions login problems, password reset, 2FA, OTP, or account locked -> Category: "account", Queue: "account_security_queue"
- If ticket asks about parcel delivery, delayed order, tracking number, courier issues -> Category: "shipping", Queue: "shipping_logistics_queue"
- If ticket provides suggestions, compliments, or general product feedback -> Category: "feedback", Queue: "customer_feedback_queue"
- If ticket mentions data breach, unauthorized access, phishing, or vulnerability -> Category: "security", Queue: "security_incident_queue"
- If ticket does not match any specific category above -> Category: "other", Queue: "general_triage_queue"
